# RentAMovie
ASP .NET MVC application for renting movies. It allows users to browse a catalog of movies, add them to their cart, and complete the rental process.
The application also includes an admin panel for managing the movie inventory and processing rentals.

## Technology
- ASP .NET MVC
- Entity Framework
- MySQL Server 
- jQuery
- HTML/CSS
- C#

## Startup
1. Clone the repository: `git clone
2. Navigate to the project directory: `cd RentAMovie`
1. Install dependencies: `dotnet restore`
1. Update the connection string in `appsettings.json` to connect to your MySQL database.
1. Run the application: `dotnet run`
1. Open a web browser and navigate to `http://localhost:5000` to access the application.
1. To access the admin panel, navigate to `http://localhost:5000/admin` and log in with the following credentials:
   - Username: admin
   - Password: password.
